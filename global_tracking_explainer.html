AX Parking · Tracking overview

카메라가 바뀌어도
같은 차량일까?

차량의 BEV 위치 기록으로 움직임을 추정하고, 화면에서 사라진 동안의 예상 위치와 재등장한 차량의 움직임을 비교해 Global ID를 이어 붙이는 흐름입니다.

한눈에 보는 흐름
① 위치 기록차량 중심을 BEV 좌표로 모음
② 속도 추정최근 좌표에서 vx, vy 계산
③ 위치 예측마지막 위치에서 직선 외삽
④ 후보 비교거리·시간·방향·속도 점수화
⑤ ID 연결가장 그럴듯한 Global ID 선택

1. 위치 기록에서 속도와 방향을 구한다

BEV 좌표는 카메라 영상의 점을 탑뷰 좌표로 바꾼 위치입니다. 최근 위치 여러 개에 선형 회귀를 적용해 X/Y축 속도를 각각 구합니다.

코드에서 볼 곳 · 399–464행
global_tracker.py · _linear_velocity / _direction / _append_global_history 
vx = 위치 변화량(x) / 시간 변화량
vy = 위치 변화량(y) / 시간 변화량

speed = hypot(vx, vy)
direction = (vx / speed, vy / speed)

실제 코드는 최근 샘플의 평균을 기준으로 선형 회귀를 계산합니다. 두 성분 velocity_x, velocity_y가 속도 벡터이고, 정규화한 벡터가 방향입니다.

트랙에 보관되는 값 · 148–199행
global_tracker.py · GlobalTrack / predicted_position 
last_bev_x, last_bev_y  # 마지막 위치
velocity_x, velocity_y  # BEV 속도 벡터
direction_x, direction_y
speed_px_per_sec

매 프레임 위치를 쌓고 속도를 다시 계산합니다. 기록 길이는 설정의 motion_history_sec를 따릅니다.

설정값: 최근 0.8초의 BEV 위치 사용

2. 사라진 동안의 위치를 예측한다

복잡한 차량 동역학 모델이 아니라, 마지막 속도가 잠시 유지된다는 가정의 직선 예측입니다.

코드에서 볼 곳 · 191–199행
global_tracker.py · GlobalTrack.predicted_position
예상 위치 = 마지막 BEV 위치 + 속도 벡터 × 경과 시간 
predicted_x = last_bev_x + velocity_x * time_gap
predicted_y = last_bev_y + velocity_y * time_gap

이 예상 위치와 새 카메라에서 관측된 BEV 위치 사이의 거리가 후보 평가에 쓰입니다.

3. 새 관측이 기존 차량인지 점수로 비교한다

시간 간격이 허용 범위 안인지 먼저 확인하고, 위치가 너무 멀면 후보에서 제외합니다. 남은 후보는 낮은 점수일수록 더 잘 맞는 것으로 봅니다.

코드에서 볼 곳 · 738–863행
global_tracker.py · _candidate_score
55%예측 위치와의 거리
25%진행 방향 차이
10%시간 간격
10%속력 차이
총점 = 가중 평균(위치 점수, 방향 점수, 시간 점수, 속력 점수)
점수 > max_match_score → 후보에서 제외
후보 목록 → 점수가 낮은 순으로 정렬

설정 출처: global_tracking.yaml · 110–143행. 방향·속력은 양쪽 모두 최소 속도 기준을 넘었을 때만 점수에 들어갑니다. 아직 움직임 정보가 부족하면 해당 항목을 빼고 나머지 가중치를 다시 정규화합니다.

해석할 때 주의: 이 점수는 확률이 아닙니다. 코드의 규칙에 따라 후보를 비교하는 비용 점수이며, 값이 작을수록 선호됩니다.

4. 방향이 바뀌거나 속도가 느릴 때는?

방향 반대 후보 제외 · 설정 143행

속도 정보가 충분한데 방향 차이가 direction_hard_limit_deg보다 크면 같은 차량 후보로 보지 않습니다. 현재 설정 한계는 120°입니다.

단, 이 기준을 적용할 만큼 속도가 크지 않으면 방향·속력 점수는 생략됩니다.

실제 BEV 이동으로 보조 확인 · 1286행부터
global_tracker.py · bev_motion_matches

새 트랙이 BEV에서 충분히 꾸준히 움직였는지, 기존 차량의 속도 벡터와 방향·속력이 비슷한지 추가로 확인합니다. 기존 트랙이 거의 멈춘 상태로 사라졌다면 방향 비교 대신 ACTIVE 상태 여부를 확인하는 분기도 있습니다.

발표에서 이렇게 말하면 됩니다

“최근 이동으로 다음 위치를 예상하고,
재등장 차량과 여러 단서를 비교합니다.”

차량의 BEV 위치 기록으로 X/Y 속도 벡터를 계산합니다. 차량이 화면에서 사라지면 마지막 위치와 속도로 위치를 직선 예측합니다. 다른 카메라의 새 관측이 시간·거리 조건에 맞는지 확인한 뒤, 위치·방향·속력·시간 점수를 합쳐 기존 Global ID와 연결할지 판단합니다.

핵심 순서: _linear_velocity (399행) → predicted_position (191행) → _candidate_score (738행) → _candidate_list (865행).

이 페이지는 코드 설명용 요약입니다. 코드 위치는 현재 작업본 기준이며, 실제 구현은 src/tracking/global_tracker.py, 점수 비중과 임계값은 config/global_tracking.yaml에서 확인할 수 있습니다.
