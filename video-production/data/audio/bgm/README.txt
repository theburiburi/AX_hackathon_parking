배경음악(BGM) 파일 위치.

여기에 mp3 / m4a / wav / ogg 파일을 넣으면 검토 화면 하단 "BGM" 목록에 파일 이름으로 나타난다.
  - 영상 시각에 맞춰 재생되고, 음악이 영상보다 짧으면 처음부터 반복(루프)한다.
  - 기본 선택 · 음량 · 페이드: src/config/playback.js 의 bgm
  - URL 로 고르기: ?bgm=파일이름 (확장자 제외), 끄기: ?bgm=0
  - 저장소에 넣기 전에 사용 허락(라이선스)을 확인한다.
목록에 없는 파일은 검토 화면의 "파일 열기"로 바로 들어 볼 수 있다 (새로 고치면 사라짐).
