## 2. 현재 구현 기준 — 참고용

- `TrackedVehicle`: `track_id`, `class_id`, `confidence`, `bbox`.
- `DetectedVehicle`: `class_id`, `confidence`, `bbox`. 다중 카메라 검출에는 지속되는 track ID가 없다.
- bbox는 원본 CCTV 픽셀의 `(x1, y1, x2, y2)`, ground point는 하단 중앙이다.
- Homography 결과는 BEV 지도 이미지의 픽셀 좌표다. 미터 단위가 아니다.
- 보정 데이터는 `image_points`, `bev_points`, `is_sample`, `ransac_reproj_threshold`를 사용한다.
- `read_at(global_time_ms)`는 입력 카메라 순서의 프레임 목록을 반환한다.
- `offset_frames / fps`는 초 단위 오프셋이며 양수는 해당 영상을 앞서 읽는다.
- 기존 결과의 `detection_id`는 프레임 내 번호이며 local/global track ID가 아니다.
- Global ID와 동일 차량의 위치 통합은 아직 구현되지 않았다.
